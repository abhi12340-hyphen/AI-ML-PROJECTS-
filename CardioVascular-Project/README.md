# CardioVascular Disease Prediction 
This project uses machine learning models to predict whether a person has a cardiovascualar disease or not .

## Technologies Used 
- Python 
- Pandas , numpy
- Scikit-learn 
- Matplotlib, Seaborn 

### Models Used 
- Logistic Regression 
- KNN 
- Decision Tree
- SVM
- Random Forest 

#### Result
Random Forest achieved the highest accuracy and was selected as the final model. 

##### DataSet 
Cardio Train Dataset 

###### Conclusion 
Machine Learning models can effectively predict the heart disease using patient data.
